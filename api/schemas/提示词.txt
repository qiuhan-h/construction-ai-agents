【生成文件 7】response_schemas.py
================================================================================
你是一名 Python 后端开发者。请实现 response_schemas.py。

【背景】
API 层统一响应结构。 设计要点： - 所有 API 接口统一返回 ApiResponse[T] 形式，简化前端处理； - code / message / data 三段式； - code 字段为字符串，承载业务错误码（与 common.error_codes 配合）； - 分页响应使用 Page[T]（pagination.py）； - 当 data 为 None 且 request_id 存在时，自动填充 request_id，便于链路追踪。

【依赖】
- from __future__ import annotations
- from typing import Any, Generic, TypeVar
- from pydantic import BaseModel, ConfigDict, Field

【关键常量】
- T

【必须实现的类】
1. class ApiResponse(BaseModel, Generic[T])：统一 API 响应。 示例： ApiResponse[dict](code="0", message="ok", data={"id": "prj_..."}) ApiResponse[str].ok("hi") ApiResponse[Any].fail("50002", "bad", details={"x": 1})
   方法：
   - ok(cls, data: T | None, message: str, request_id: str | None=None) -> 'ApiResponse[T]'
   - fail(cls, code: str, message: str, details: dict[str, Any] | None, request_id: str | None, http_status: int | None) -> 'ApiResponse[T]'
   - from_exception(cls, exc: Exception, request_id: str | None) -> 'ApiResponse[Any]'  # 从 AppException 派生响应。
1. class ErrorDetail(BaseModel)：单条错误明细（用于表单/参数级校验错误）。
1. class ErrorResponse(BaseModel)：API 错误响应体（用于 4xx/5xx 响应）。
