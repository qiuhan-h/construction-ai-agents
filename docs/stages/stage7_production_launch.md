# 阶段 7 · 正式上线

> 版本：2026-09-03
> 周期：1 周（5 工作日）
> 前置：6 试运行签字确认
> 后置：进入运营期

## 1. 目标

把试运行验证通过的产品正式对外服务。核心是**合规可备案、SLA 可承诺、运维 7×24 可值守**，三件缺一不可。

## 2. 关键交付物

### 2.1 合规备案

- **数据合规**
  - 数据出境合规评估报告（涉及 InfluxDB Cloud / 第三方 LLM）
  - 个人信息保护影响评估（PIPIA）
  - 数据处理协议（DPA）模板
  - 客户数据隔离架构图（5b.3 多租户 + K8s namespace + 物理资源池）
  - 数据保留策略：审查报告永久 / IoT 时序 1 年 / 日志 90 天 / 审计日志 3 年
  - 数据删除流程：客户退出 7 天内物理删除
- **AI 合规**
  - 算法备案（生成式 AI 服务算法备案清单）
  - 智能体决策可解释性白皮书（依据法规 / 案例 / 计算的可追溯链路）
  - 人工复核流程图 + 客户使用培训
  - 模型版本登记表（每次 LLM / Embedding 升级均需登记）
- **资质**
  - ISO 27001 信息安全管理体系（建议 6-9 个月内取）
  - 等保 2.0 三级（建议 12 个月内取）
  - 软件著作权登记（已在 1 阶段完成）
  - 专利布局（建议 6 个月内提交 2-3 件）
- **法务**
  - 主服务协议 MSA 模板
  - 服务等级协议 SLA 合同（与商务共拟）
  - 隐私政策 / 用户协议 / Cookie 政策
  - 客户数据授权书模板

### 2.2 生产部署

- `make deploy-prod` — 一键部署到生产 K8s
- 生产环境就绪检查（Go-Live Checklist）：
  - 5 个服务全活 + 健康检查 200
  - 数据库主备 / Redis 集群 / InfluxDB 集群状态正常
  - 监控 / 告警 / 状态页全部就位
  - CDN / WAF / DDoS 防护开启
  - TLS 证书 + 域名解析生效
  - 凭据全部走 K8s Secret / Vault
- 数据迁移：试点 / 公测数据正式化（已合规脱敏）
- 备份策略：DB 每日全量 + 6 小时增量 / OSS 跨区复制 / 7 天保留
- 灾备：异地（同城不同可用区）灾备，RPO ≤ 5min / RTO ≤ 30min

### 2.3 SLA 监控

- 4 个核心 SLI 实时计算 + 仪表板：
  - 可用性（按月统计）
  - API P95 延迟
  - 报告生成 P95
  - 通知到达率
- 错误预算（Error Budget）告警：
  - 50% 耗尽：通知 SRE
  - 80% 耗尽：暂停非紧急变更
  - 100% 耗尽：暂停所有非 P0 变更 + 客户公告
- 客户月报：每月 1 日自动生成，含 SLA 达成率 + 故障总结 + 容量规划

### 2.4 运维手册与值守

- `docs/operations/runbook.md` — 应急操作手册：
  - 服务故障排查（按症状 → 命令 → 期望结果）
  - 数据库恢复
  - 灾备切换
  - 紧急回滚
  - 安全事件响应
  - 数据泄露应急
- `docs/operations/oncall.md` — 值守手册：
  - 7×24 排班（建议 3 人轮转）
  - 告警响应 SLA（P0 ≤ 15min / P1 ≤ 1h / P2 ≤ 4h）
  - 升级路径（SRE → 架构师 → CTO）
  - 沟通模板（客户公告 / 内部升级 / 复盘邮件）
- `docs/operations/change_management.md` — 变更管理：
  - 变更窗口（每周二/四 22:00-02:00）
  - 变更审批（普通变更 / 紧急变更）
  - 灰度 / 回滚强制
- 培训：SRE 团队 1 周集中培训 + 演练 1 次
- 复盘：上线后 1 周 / 1 月 / 3 月三次复盘

## 5. 风险与回退

| 风险 | 概率 | 影响 | 缓解 / 回退 |
| --- | --- | --- | --- |
| 合规备案延迟 | 中 | 高 | 提前 1 个月启动；并行推进 AI / 数据 / 资质 |
| 生产首次故障 | 中 | 高 | 灰度 10% → 50% → 100% × 24h；监控 + 5min 内回滚 |
| SLA 指标未达 | 中 | 高 | 客户赔偿条款 + 错误预算控制 + 容量规划 |
| 7×24 值守人员不足 | 中 | 高 | 培训 3 人以上备份 + 跨团队支援 |
| 客户对 SLA 不买账 | 低 | 中 | 灵活分级：标准版 / 企业版 / 旗舰版 |
| 安全事件 | 低 | 致命 | 应急响应 Runbook + 通报机制 + 备份恢复 |

## 6. 阶段出口（正式上线）

- 合规备案受理回执（部分项目可后续补充）；
- 生产环境 5 服务正式对外服务；
- SLA 合同首批客户已签；
- 7×24 运维就位 + 首次演练通过；
- 上线公告对外发布；
- 复盘计划（1 周 / 1 月 / 3 月）已排入日历；
- 进入 **运营期**：按月度回顾 + 季度版本迭代。

## 7. 运营期（持续）

进入运营期后，常规工作流：

- **每月**：月报 + 月度客户回访 + 月度容量评审
- **每季度**：版本迭代 + 客户培训 + SLA 回顾
- **每半年**：合规自评 + 灾备演练 + 安全审计
- **每年**：合规复检 + 资质续期 + 战略评审

技术债务管理、Feature Roadmap、客户定制需求、商务扩张等议题，按"季度规划会"节奏推进。
