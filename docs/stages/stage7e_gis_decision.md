## 决策选项

### 选项 A：立项实现（推荐）

**优点**：
- 项目已有 3 处引用，功能是完整链路的一环
- GIS 可视化是建筑现场监控的核心需求
- 第三方库成熟（folium/geojson/rtree）

**缺点**：
- 需投入开发资源
- 依赖外部地图服务（可选高德/天地图 API）

**实现范围**：
- GIS 数据模型（GeoJSON 格式）
- 地图渲染引擎（folium 基础）
- 空间查询（rtree 索引）
- 与 BIM 模型联动（IFC 坐标系转换）

### 选项 B：延后实现

**优点**：
- 不阻塞上线
- 降级模式下 GIS 端点返回空数据

**缺点**：
- 移动端 05_gis_viewer 页面不可用
- 现场监控缺少空间维度

### 选项 C：第三方集成

**优点**：
- 快速集成
- 功能完整

**缺点**：
- 增加外部依赖
- 数据隐私风险

## 建议方案

**采用选项 A，分阶段实施**：
1. 阶段八 8a：GeoJSON 数据模型 + folium 基础渲染
2. 阶段八 8b：与 BIM 联动（坐标系转换）
3. 阶段八 8c：空间查询优化
