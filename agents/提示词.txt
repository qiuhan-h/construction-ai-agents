【生成文件 2】base_agent.py
================================================================================
你是一名 Python 后端开发者。请实现 base_agent.py。

【背景】
智能体抽象基类。 设计目标： - 业务智能体（safety_audit / compliance / site_monitor）通过继承 BaseAgent 获得"被 A2A 路由、被 MCP 调用、发事件"的统一能力； - 基类不依赖 core.llm / core.mcp / core.events 的具体实现（保持解耦）， 业务层按需 import； - 阶段二仅提供骨架与 A2A 接入骨架； 阶段三/四在子类中实现 handle / get_task / cancel_task 等业务方法。 约定： - 子类必须设置类属性 name（与 AgentName 枚举一致）； - 子类必须设置类属性 version； - 构造时必传 tenant_id（每个智能体实例绑定到一个租户）； - 子类通过 self.publish_event(...) 发事件，self.a2a 客户端调用其它智能体， self.mcp 客户端调用 MCP 工具/资源（按需注入，避免硬依赖）。

【依赖】

   方法：
   - __init__(self, tenant_id: str, a2a_url: str, card_path: str, metadata: dict[str, Any] | None) -> None
