【生成文件 5】vector_store.py
================================================================================
你是一名 Python 后端开发者。请实现 vector_store.py。

【背景】
向量库抽象与首版（内存版）实现。 设计： - VectorStore：抽象接口（upsert / query / delete / count） - InMemoryVectorStore：纯 Python + 数学库实现（无第三方依赖） - 分词：unicode 字符 + 简单停用词过滤 - 向量化：词袋 + 词频 → L2 归一化 - 相似度：cosine 阶段四将用 ChromaDB 替换 InMemoryVectorStore，对外接口保持不变。

【依赖】
- from __future__ import annotations
- import asyncio
- import math
- import re
- import threading
- from abc import ABC, abstractmethod
- from collections import Counter
- from dataclasses import dataclass, field
- from typing import Any, Iterable

【关键常量】
- _TOKEN_PATTERN

【必须实现的类】
1. class VectorRecord：一条向量记录。
1. class VectorHit：一条检索结果。
1. class VectorStore(ABC)：向量库抽象接口（阶段四 ChromaDB 实现将继承此）。
   方法：
   - async upsert(self, records: list[VectorRecord]) -> int
   - async query(self, tenant_id: str, text: str, top_k: int, filter: dict[str, Any] | None, min_score: float) -> list[VectorHit]
   - async delete(self, ids: Iterable[str]) -> int
   - count(self, tenant_id: str | None=None) -> int
1. class InMemoryVectorStore(VectorStore)：内存版向量库（首版，无第三方依赖）。
   方法：
   - __init__(self) -> None
   - async upsert(self, records: list[VectorRecord]) -> int
   - _upsert_sync(self, records: list[VectorRecord]) -> int
   - async query(self, tenant_id: str, text: str, top_k: int, filter: dict[str, Any] | None, min_score: float) -> list[VectorHit]
   - _query_sync(self, tenant_id: str, text: str, top_k: int, filter: dict[str, Any] | None, min_score: float) -> list[VectorHit]
   - async delete(self, ids: Iterable[str]) -> int
   - _delete_sync(self, ids: list[str]) -> int
   - count(self, tenant_id: str | None=None) -> int
   - all_records(self, tenant_id: str | None=None) -> list[VectorRecord]  # 测试用：导出全部记录。

【必须实现的函数】
1. _tokenize(text: str) -> list[str]  # 简单分词：unicode 词字符 + 去停用词 + 小写。
2. get_default_vector_store() -> InMemoryVectorStore
3. reset_default_vector_store() -> None  # 测试用：重置默认向量库。
4. _to_vector(tokens: list[str]) -> dict[str, float]  # 词频向量（dict[token, count]）。 P0-4 修补：旧实做把 Counter.items() 排序后丢弃 token 名，仅保留 counts 列表，按位置 zip 配对——两个完全不相关单 token 文档会 得到 1.0 相似度。改为保留 token 名做 dict，按 key 交集算内积。
5. _cosine(a: dict[str, float], b: dict[str, float]) -> float  # 两个 dict[str, float] 间的余弦相似度。 按 key 交集算内积（token 名对齐，避免位置错配）。
6. _match_filter(metadata: dict[str, Any], flt: dict[str, Any]) -> bool  # 简单 metadata 过滤（值完全相等）。
