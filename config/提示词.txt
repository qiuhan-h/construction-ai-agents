【生成文件 5】settings.py
================================================================================
你是一名 Python 后端开发者。请实现 settings.py。

【背景】
全局配置（Pydantic Settings）。 优先级（从高到低）： 1. 进程环境变量 / .env 文件 2. 分环境 YAML 覆盖（config/environments/{app_env}.yaml） 3. 代码内默认值 使用方式： from config import get_settings settings = get_settings() ⚠️ 安全说明：所有外部地址 / 凭据占位统一为 "需要补充实际链接"。 - 涉及真实 IP / 端口 / 用户名 / 密码 / Token / Key 的位置均不得直接提交； - 占位说明仅描述填写格式与示例，不含真实凭据； - 生产环境应通过 K8s Secret / Vault 等外部注入，不写进 .env 或本文件。

【依赖】
- from __future__ import annotations
- import logging
- from functools import lru_cache
- from pathlib import Path
- from typing import Any, Literal
- import yaml
- from pydantic import Field, SecretStr, field_validator, model_validator
- from pydantic_settings import BaseSettings, SettingsConfigDict

【关键常量】
- CONFIG_DIR
- PROJECT_ROOT
- _DEFAULT_JWT_SECRET_PLACEHOLDER = '需要补充实际链接'

【必须实现的类】
1. class Settings(BaseSettings)：平台全局配置。字段名与环境变量一一对应（大小写不敏感）。
   方法：
   - _empty_mqtt_port_default(cls, v: Any) -> Any  # 空字符串（.env 中 MQTT_PORT= 留空）回退默认 1883，避免 int 解析失败。
   - _warn_default_jwt_secret(self) -> 'Settings'
   - project_root(self) -> Path
   - data_dir(self) -> Path
   - log_dir(self) -> Path

【必须实现的函数】
1. load_env_overrides(app_env: str) -> dict[str, Any]  # 读取分环境 YAML 覆盖；文件不存在时返回空字典。
2. get_settings() -> Settings  # 获取全局配置单例。 环境变量 / .env 优先于分环境 YAML：仅当字段未被环境变量显式设置时， 才应用 YAML 中的覆盖值。
3. reload_settings() -> Settings  # 清空缓存并重新加载（测试与配置热更新使用）。

【约束】
- 严格遵循上述接口签名（参数名、类型注解、返回值类型）
- 保持向后兼容，不修改已有公共接口
- 新增功能须补充对应单元测试

【输出】
完整的代码文件，使用中文 docstring 和类型注解，并在关键逻辑处添加中文行内注释。

================================================================================
目录级生成约束
================================================================================
1. 所有文件必须使用中文 docstring 和类型注解（from __future__ import annotations）
2. 严格遵循各文件【必须实现的类/函数】中定义的接口签名
3. 新增功能须补充对应单元测试，运行 pytest 确认无回归
4. 涉及环境变量的配置须同步更新 .env.example 与 config/settings.py

【中文注释规范】（所有生成的代码必须遵守）
- 模块顶部 docstring：中文说明文件职责、设计原则
- 类 docstring：中文说明类用途、关键属性
- 方法/函数 docstring：中文说明功能、参数含义、返回值
- 关键代码逻辑：必须添加中文行内注释（# 注释），解释"为什么这样做"
- 复杂分支、循环、异常处理：必须有中文注释说明意图
- 禁止使用英文注释；禁止无注释的复杂逻辑块
- 常量、枚举、配置项：必须有中文注释说明用途
