================================================================================
config/environments/ 目录代码生成提示词合集
================================================================================
本文件汇总 config/environments/ 目录下所有代码文件的"代码生成提示词"。
每一段都是一段独立的 prompt，可直接复制粘贴给大模型，让其生成对应代码文件。
分段处理，每段对应一个代码文件。生成代码时请严格遵守每段中的接口契约和约束。

================================================================================
【生成文件 1】dev.yaml
================================================================================
你是一名 Python 后端开发者。请实现 dev.yaml。

【背景】
开发环境覆盖（仅在字段未被环境变量显式设置时生效）

【约束】
- 严格遵循上述接口签名（参数名、类型注解、返回值类型）
- 保持向后兼容，不修改已有公共接口
- 新增功能须补充对应单元测试

【输出】
完整的代码文件，使用中文 docstring 和类型注解，并在关键逻辑处添加中文行内注释。

================================================================================
目录级生成约束
================================================================================
1. 所有文件必须使用中文 docstring 和类型注解（from __future__ import annotations）
2. 严格遵循各文件【必须实现的类/函数】中定义的接口签名
3. 新增功能须补充对应单元测试，运行 pytest 确认无回归
4. 涉及环境变量的配置须同步更新 .env.example 与 config/settings.py

【中文注释规范】（所有生成的代码必须遵守）
- 模块顶部 docstring：中文说明文件职责、设计原则
- 类 docstring：中文说明类用途、关键属性
- 方法/函数 docstring：中文说明功能、参数含义、返回值
- 关键代码逻辑：必须添加中文行内注释（# 注释），解释"为什么这样做"
- 复杂分支、循环、异常处理：必须有中文注释说明意图
- 禁止使用英文注释；禁止无注释的复杂逻辑块
- 常量、枚举、配置项：必须有中文注释说明用途
