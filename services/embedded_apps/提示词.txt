【背景】
钉钉 ISV 内嵌应用（6c.1）。 功能： - ``oauth_callback(code, state, timestamp)`` 免登回调： * state 与 session 中预存的 expected_state 一致 → 否则 403； * timestamp 与当前时间差 >300s → 403（防重放）； * 通过后用 code 换 userid（httpx 直连或 mock 降级）； - ``push_notification(user_ids, title, content)`` 工作通知推送。 降级策略： - 钉钉 SDK（dingtalk-sdk）缺失 → httpx 直连 OAuth API； - httpx 缺失 → mock 返回固定 userid。

【依赖】
- from __future__ import annotations
- import hashlib
- import hmac
- import logging
- import threading
- import time
- from typing import Any
- from fastapi import HTTPException, status

【关键常量】
- OAUTH_STATE_TTL = 300

【必须实现的类】
1. class DingTalkApp：钉钉 ISV 内嵌应用。
   方法：
   - __init__(self, app_key: str, app_secret: str, agent_id: str, corp_id: str) -> None
   - generate_state(self, session_id: str) -> str  # 生成 OAuth state 并存入 session。
   - oauth_callback(self, code: str, state: str, timestamp: float, session_id: str, expected_state: str | None) -> dict[str, Any]  # 钉钉 OAuth 回调：校验 state + timestamp → 换 userid。 - state mismatch → HTTPException 403（TR-8.2）； - timestamp 过期（>300s）→ HTTPException 403（TR-8.3）； - 通过后返回 ``{"userid": "...", "name": "..."}``。
   - _exchange_code_for_userid(self, code: str) -> str  # 用 authCode 换 userid。
   - push_notification(self, user_ids: list[str], title: str, content: str) -> bool  # 推送工作通知。

1. get_dingtalk_app() -> DingTalkApp
2. reset_dingtalk_app() -> None
