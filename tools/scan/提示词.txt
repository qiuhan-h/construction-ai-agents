【生成文件 9】scan_stage5.py
================================================================================
你是一名 Python 后端开发者。请实现 scan_stage5.py。

【背景】
5 阶段静态文件扫描：核对 5a（前端页面 + 组件）+ 5b（后端生产化）+ 5c（可观测/部署/CI） 所有规划文件的交付状态。 设计要点： - 按子阶段分级：5a / 5b / 5c - 空缺走 SKIP 而非 FAIL（5b / 5c 大量文件尚未实做，框架必须优雅降级） - 子阶段仅当所有前置文件就位时才进入"严格模式"（MISSING 视为 FAIL） - 4e 已就位文件作为 "precondition" 先校验，避免 5a 的 scan 把 4e 缺失误判 退出码： - 0  5a + 4e 全部 OK；5b / 5c 可选 OK 或 SKIP - 1  5a 或 4e 存在缺失/导入失败 运行：python tools/scan_stage5.py python tools/scan_stage5.py --strict     # 5b/5c 也视为严格 python tools/scan_stage5.py --only 5a    # 只扫 5a

【依赖】
- from __future__ import annotations
- import argparse
- import importlib
- import sys
- from pathlib import Path

【关键常量】
- ROOT

【必须实现的函数】
1. _scan_files(stage: str, files: list[tuple[str, str]], strict: bool) -> tuple[list[str], int, int]  # 扫描一组文件。返回 (失败列表, OK 数, SKIP 数)。 strict=False：缺失/空文件 -> SKIP；strict=True -> FAIL
2. _scan_modules(modules: list[str]) -> tuple[list[str], int]  # 扫描一组模块。返回 (失败列表, OK 数)。缺失模块走 SKIP。
3. _scan_exports(exports: list[tuple[str, str]]) -> tuple[list[str], int]  # 扫描关键 export。缺失走 SKIP（文件未实做），未到 strict 模式不视为 FAIL。
4. main() -> int
5. _summary(fails: list[str], total_ok: int, total_skip: int, pre_ok: int, a_ok: int, b_ok: int, c_ok: int, args: argparse.Namespace) -> int

【约束】
- 严格遵循上述接口签名（参数名、类型注解、返回值类型）
- 保持向后兼容，不修改已有公共接口
- 新增功能须补充对应单元测试

【输出】
完整的代码文件，使用中文 docstring 和类型注解，并在关键逻辑处添加中文行内注释。

【中文注释规范】（所有生成的代码必须遵守）
- 模块顶部 docstring：中文说明文件职责、设计原则
- 类 docstring：中文说明类用途、关键属性
- 方法/函数 docstring：中文说明功能、参数含义、返回值
- 关键代码逻辑：必须添加中文行内注释（# 注释），解释"为什么这样做"
- 复杂分支、循环、异常处理：必须有中文注释说明意图
- 禁止使用英文注释；禁止无注释的复杂逻辑块
- 常量、枚举、配置项：必须有中文注释说明用途
