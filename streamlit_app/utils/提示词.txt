【生成文件 2】api_client.py
================================================================================
你是一名 Python 后端开发者。请实现 api_client.py。

【背景】
同步 HTTP 客户端（Streamlit 友好）。 约定： - 默认 base_url 从 settings.api_base_url 读（或环境变量 API_BASE_URL）； - 默认 Authorization 走 dev- 前缀 token，格式：dev-{tenant_id}-{user_id}； - 响应统一走 ApiResponse 形状（4d 已约定）；失败抛 APIError，message / code 可直接 st.error； - 不依赖 langchain / orchestrator 内部模块，仅 httpx + os。

【依赖】
- from __future__ import annotations
- import logging
- import os
- from typing import Any
- from urllib.parse import urljoin
- import httpx

【必须实现的类】
1. class APIError(RuntimeError)：API 调用失败的统一异常。
   方法：
   - __init__(self, message: str, code: str='', status: int=0, data: Any=None) -> None
1. class APIClient：Streamlit 侧同步 HTTP 客户端。
   方法：
   - __init__(self, base_url: str | None=None, token: str | None=None, timeout: float=15.0) -> None
   - configure(self, base_url: str | None=None, token: str | None=None) -> None
   - auth_headers(self) -> dict[str, str]
   - _request(self, method: str, path: str, params: dict | None, json_body: dict | None, raw: bool) -> Any
   - healthz(self) -> dict
   - readyz(self) -> dict
   - list_supported_agents(self) -> list[str]
   - get_agent_card(self, name: str) -> dict
   - list_workflows(self) -> dict
   - get_workflow(self, name: str) -> dict
   - trigger_workflow(self, name: str, payload: dict | None, via_query: bool=None) -> dict  # 触发工作流。 - via_query=False（默认）：payload 作 body JSON； - via_query=True：payload 作 ?payload={...}（兼容 4d query 入口）。
   - get_run(self, run_id: str) -> dict
   - list_timeline(self, limit: int | None=None) -> dict
   - get_stats(self) -> dict
   - list_reports(self, project_id: str | None=None, page: int=1, page_size: int=20) -> dict
   - mobile_dashboard(self) -> dict  # 移动端首页仪表盘（聚合 KPI + 最近告警 + 项目卡片，< 5KB）。
   - mobile_alerts(self) -> list  # 移动端告警列表（≤20 条精简字段）。
   - mobile_projects(self) -> list  # 移动端项目卡片列表（≤10 个）。
   - close(self) -> None

【必须实现的函数】
1. api_client() -> APIClient  # 获取当前会话的 API 客户端。 - Streamlit 可用：按 ``st.session_state`` 隔离客户端，避免多用户共享 token 导致的跨租户串户； - Streamlit 不可用（CLI / 单元测试 / 无 streamlit 环境）：回退到模块级单例。
